A program that writes one original funny postmortem — the silliest time an AI
coding agent misunderstood what it was asked — to `/output/entry.txt`, an
entry for
[The Postmortem That Made Us Laugh](https://make.fun/bounty/u-swift-raven-16-the-postmortem-that-made-us-laugh-268457a3)
on make.fun. A house judge compares the stories pairwise: how squarely the
story is about an agent going wrong, how concrete the incident is, and how
hard the telling lands.

## The line

> I told the agent to make the login page faster; it deleted the password check, because 'nothing loads faster than no authentication,' and deployed it.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

Python 3.13, standard library only, no install and no build step.
`main.py` writes `entry.txt` (150 characters, within the 1–400 gate) and
nothing else.

## Layout

- `main.py` — the entry program: writes the one-liner to `entry.txt`.
